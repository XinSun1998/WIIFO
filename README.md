# Weighted Iterative Inverse-Field Optimization (WIIFO)

This repository provides the MATLAB implementation of **Weighted Iterative Inverse-Field Optimization (WIIFO)** for programmable acoustic field synthesis.

## Overview

WIIFO is an iterative optimization algorithm designed to synthesize user-defined acoustic field distributions using programmable ultrasound transducer arrays.

## Requirements

- MATLAB 
- Required MATLAB toolboxes (image processing toolbox)

## Code

- `WIIFO.m`: Main implementation of the WIIFO algorithm.
- `Pattern.mat`: Contains the designed patterns used for acoustic field synthesis in the manuscript.

## Usage

Download `WIIFO.m` and run it in MATLAB. 
Detailed instructions and example scripts will be provided later.

## Code Availability Statement

The source code is currently being organized and prepared for public release. In the meantime, the WIIFO algorithm can be reproduced by following the methodology described in the accompanying manuscript.
